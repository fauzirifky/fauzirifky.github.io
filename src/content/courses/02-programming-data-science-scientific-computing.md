## Deskripsi Mata Kuliah

Mata kuliah ini membangun kompetensi dasar pemrograman untuk pemecahan masalah, pengolahan data, dan komputasi ilmiah. Pembelajaran menekankan logika program, perancangan algoritma, implementasi Python, pengujian, analisis kompleksitas, serta pengenalan metode ilmu data.

## Fokus Utama

Penguasaan dasar pemrograman Python, algoritma, serta penerapan teknik ilmu data dasar untuk penyelesaian masalah nyata berbasis proyek.

## Pokok Bahasan

- Dasar Python
- Fungsi dan rekursi
- Unit testing
- Struktur data: list dan NumPy
- Flowchart dan pseudocode
- Kompleksitas Big-O
- Algoritma sorting
- Operasi matriks dan aljabar linier
- Regresi Linier
- k-Nearest Neighbors (kNN)
- k-Means
